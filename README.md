# CSS Learning Module – Basics to Advanced

Welcome to **CSS Learning Module**, a hands-on repository for learning Cascading Style Sheets (CSS), from basic syntax to modern web layouts, responsive design, and animations.

This repository contains topic-wise examples and frontend practice projects designed to help students understand CSS through practical coding.

## 📚 Topics Covered

| No. | Topic | Description |
|---|---|---|
| 01 | CSS Basic Syntax | Rules, properties, and values |
| 02 | Introduction to CSS | Applying styles to HTML elements |
| 03 | CSS Selectors | Element, class, ID, and other selectors |
| 04 | Colors | Applying colors to web elements |
| 05 | Backgrounds | Background colors and images |
| 06 | Fonts | Font families, sizes, and styles |
| 07 | Text Alignment | Text positioning and presentation |
| 08 | Icons | Adding and styling icons |
| 09 | Box Model | Content, padding, borders, and margins |
| 10 | Flexbox | Flexible layouts and element alignment |
| 11 | CSS Grid | Two-dimensional layouts |
| 12 | Responsive Design | Adapting pages to different screen sizes |
| 13 | Animations | CSS animations and visual effects |

## 🚀 Getting Started

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/CSS-learning-module-basics.git
```

### Step 2: Open the Project in VS Code

```bash
cd CSS-learning-module-basics
code .
```

### Step 3: Run the Examples

Open an HTML file in your browser to view the page. Alternatively, install the **Live Server** extension in Visual Studio Code to preview changes while editing.

Make sure the HTML, CSS, and asset file paths remain correct when opening projects inside subfolders.

## 🎯 Learning Objectives

- Understand CSS syntax, selectors, and properties.
- Style elements using colors, backgrounds, fonts, and text properties.
- Control spacing and alignment using the box model.
- Build layouts using Flexbox and CSS Grid.
- Create responsive web pages.
- Apply transitions and animations.
- Develop practical frontend design skills.

## 💡 Recommended Learning Path

1. Learn CSS syntax and selectors.
2. Practise colors, backgrounds, fonts, and text styling.
3. Master the box model and spacing.
4. Learn Flexbox and Grid layouts.
5. Build responsive designs.
6. Explore CSS animations.
7. Apply your learning to the included projects.
